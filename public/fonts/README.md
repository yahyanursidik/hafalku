# Amiri Quran Regular

`amiri-quran-regular.ttf` is bundled locally so Qur’anic signs and diacritics do not rely on a visitor’s device font.

- Family: Amiri Quran
- Source: Google Fonts
- License: SIL Open Font License 1.1
- Upstream: https://fonts.google.com/specimen/Amiri+Quran

The application uses this font only for elements marked `lang="ar"`. Arabic source text remains unchanged.
